# System Status Monitor

A lightweight Python utility using `rich`, `psutil`, and `httpx` to display real-time system metrics (CPU utilization, Memory utilization, and public IP).

## Setup & Usage

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the monitor:
   ```bash
   python gemini-code-1789302005818.py
   ```
